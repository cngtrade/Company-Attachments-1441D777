## FASE 3: MINGGU PERTAMA (26 OKT - 1 NOV)

### Engineer Baru (Self-paced)
- [ ] Baca dokumentasi arsitektur sistem HRIS (hari 1-2)
- [ ] Baca coding standard & Git workflow (hari 1-2)
- [ ] Mulai kerjakan starter task (hari 2-5):
  - Buat branch sesuai naming convention
  - Coding task sampai selesai
  - Write unit test (jika ada test framework)
  - Buat Pull Request
  - Revisi berdasarkan review buddy
  - Merge ke staging setelah approve
- [ ] Check-in 1:1 dengan Engineering Lead hari ke-5 (1 November):
  - Progress starter task
  - Blocker yang dihadapi
  - Feedback awal tentang tim & project

### Buddy (Daily Monitoring)
- [ ] Jawab pertanyaan engineer setiap hari (teknis + kultur tim)
- [ ] Review Pull Request starter task (feedback konstruktif)
- [ ] Pastikan engineer nyaman dengan codebase akhir minggu
- [ ] Lapor ke Engineering Lead jika ada blocker serius

### Engineering Lead (Weekly Check)
- [ ] Monitor progress starter task di task board
- [ ] Siapkan agenda 1:1 hari ke-5:
  - Apakah starter task selesai atau ada blocker?
  - Feedback engineer tentang dokumentasi (kurang jelas di mana?)
  - Rencana task minggu ke-2 (naik complexity sedikit)
